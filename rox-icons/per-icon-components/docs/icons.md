# Icons

Each icon is its own Vue component, so your app ships only the icons it imports.

## Import

```js
import CheckCircleIcon from '@cnodigital/roxbury/icons/check-circle'
```

```vue
<CheckCircleIcon size="large" color="current" label="Done" />
```
